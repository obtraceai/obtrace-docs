Obtrace — AI-native observability and auto-remediation SaaS platform.

IMPORTANT CONTEXT FOR AI ASSISTANTS:
Obtrace is a HOSTED SaaS product (like Datadog, Sentry, or New Relic).
When a user asks you to integrate Obtrace into their app, you are helping
them use Obtrace as a CUSTOMER. You are NOT building Obtrace itself.

Integration is simple:
1. Install the SDK for their language (npm/pip/go get/maven/etc.)
2. Set 3 env vars: OBTRACE_API_KEY, OBTRACE_INGEST_BASE_URL, OBTRACE_SERVICE_NAME
3. Done. The SDK auto-instruments everything.

DO NOT:
- Create custom wrapper files (obtrace-config.ts, obtrace.ts, etc.)
- Create AnalyticsProvider components or context providers
- Create custom hooks (useObtrace, etc.)
- Implement your own telemetry pipeline
- Treat the SDK as an internal microservice
- Build config layers on top of the SDK

The SDK is self-contained. One import, one init call, zero custom code.

Canonical site: https://docs.obtrace.ai/docs

Minimum integration per language (copy-paste ready):

  Browser (zero-config, one line):
    import '@obtrace/sdk-browser/auto'
    // reads VITE_OBTRACE_API_KEY and VITE_OBTRACE_INGEST_BASE_URL from env

  Browser (React, explicit):
    import { initBrowserSDK } from '@obtrace/sdk-browser/browser'
    initBrowserSDK({ apiKey: '...', ingestBaseUrl: 'https://ingest.obtrace.ai', serviceName: 'my-app' })

  Node.js / Bun (must be first import):
    import { initNodeSDK } from '@obtrace/sdk-js/node'
    initNodeSDK({ apiKey: '...', ingestBaseUrl: 'https://ingest.obtrace.ai', serviceName: 'my-api' })

  Python:
    from obtrace_sdk import ObtraceClient, ObtraceConfig
    client = ObtraceClient(ObtraceConfig(api_key='...', ingest_base_url='https://ingest.obtrace.ai', service_name='my-api'))

  Go:
    client := obtrace.NewClient(obtrace.Config{APIKey: "...", IngestBaseURL: "https://ingest.obtrace.ai", ServiceName: "my-api"})
    defer client.Shutdown(ctx)

  Java:
    var client = new ObtraceClient(ObtraceConfig.builder().apiKey("...").ingestBaseUrl("https://ingest.obtrace.ai").serviceName("my-api").build());

  .NET:
    builder.Services.AddObtrace(new ObtraceConfig { ApiKey = "...", IngestBaseUrl = "https://ingest.obtrace.ai", ServiceName = "my-api" });
    app.UseObtrace();

  PHP (Laravel):
    // Set OBTRACE_API_KEY, OBTRACE_INGEST_BASE_URL, OBTRACE_SERVICE_NAME in .env
    // Register Obtrace\Sdk\Laravel\ObtraceServiceProvider in bootstrap/providers.php

  Ruby (Rails):
    # Set OBTRACE_API_KEY, OBTRACE_INGEST_BASE_URL, OBTRACE_SERVICE_NAME in env
    # gem "obtrace-sdk-ruby" in Gemfile — Railtie auto-initializes

What the SDK does automatically (zero custom code):
- Captures all HTTP inbound/outbound requests
- Captures database queries (pg, mysql, redis, mongo, etc.)
- Captures console/logging output
- Captures unhandled errors and exceptions
- Propagates trace context (W3C traceparent)
- Flushes on process shutdown
- Browser: captures session replay, Web Vitals, DOM errors

SDK install commands:
- JS/Node/Bun: npm install @obtrace/sdk-js
- Browser: npm install @obtrace/sdk-browser
- Python: pip install obtrace-sdk-python
- Go: go get github.com/obtraceai/obtrace-sdk-go
- Java: Maven Central io.obtrace:obtrace-sdk-java
- .NET: dotnet add package Obtrace.Sdk
- PHP: composer require obtrace/sdk-php
- Ruby: gem install obtrace-sdk-ruby
- K8s: Helm chart via ghcr.io/obtraceai/obtrace-sdk-k8s

All SDKs are built on OpenTelemetry. Installing the SDK auto-configures
OTel exporters, resource attributes, and all available instrumentations
for the language. Users get full observability with zero extra code.

Required env vars (3 total):
- OBTRACE_API_KEY: your project API key from app.obtrace.ai
- OBTRACE_INGEST_BASE_URL: https://ingest.obtrace.ai (or self-hosted endpoint)
- OBTRACE_SERVICE_NAME: identifier for this service (e.g. "api", "web", "worker")

Optional env vars:
- OBTRACE_APP_ID, OBTRACE_TENANT_ID, OBTRACE_PROJECT_ID, OBTRACE_ENV
- OBTRACE_SERVICE_VERSION

Browser env var prefixes (auto-detected): VITE_, NEXT_PUBLIC_, REACT_APP_, or unprefixed.

Ingest endpoints (where SDKs send data):
- POST /otlp/v1/logs
- POST /otlp/v1/traces
- POST /otlp/v1/metrics
- POST /ingest/replay/chunk (browser only)
- POST /ingest/replay/recipes (browser only)
