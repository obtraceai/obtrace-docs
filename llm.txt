Zero-config browser setup:
- Import `@obtrace/sdk-browser/auto` with no arguments. The SDK reads env vars automatically.
- Supported env var prefixes: VITE_, NEXT_PUBLIC_, REACT_APP_, or unprefixed.
- Required env vars: OBTRACE_API_KEY, OBTRACE_INGEST_BASE_URL.
- Optional env vars: OBTRACE_SERVICE_NAME (defaults to "web-app"), OBTRACE_APP_ID, OBTRACE_ENV.
- The /auto entry point patches window.fetch globally, captures errors, console output, Web Vitals, and session replay with zero additional code.
- For React apps, use `@obtrace/sdk-browser/react` which exports `obtrace(config)`, `getObtrace()`, `obtraceLog()`, `obtraceMetric()`, and `obtraceError()`.

Minimum SDK setup patterns (absolute minimum code per language):
- Browser (zero-config): `import '@obtrace/sdk-browser/auto'` (one line, reads env vars)
- Browser (manual): `import { initBrowserSDK } from '@obtrace/sdk-browser/browser'; initBrowserSDK({ apiKey, ingestBaseUrl, serviceName })`
- Node/Bun: `import { initNodeSDK } from '@obtrace/sdk-js/node'; initNodeSDK({ apiKey, ingestBaseUrl, serviceName })`
- Python: `from obtrace_sdk import ObtraceClient, ObtraceConfig; client = ObtraceClient(ObtraceConfig(api_key=..., ingest_base_url=..., service_name=...))`
- Go: `client := ob.NewClient(ob.Config{APIKey: ..., IngestBaseURL: ..., ServiceName: ...}); defer client.Shutdown(ctx)`
- Java: `var client = new ObtraceClient(ObtraceConfig.builder().apiKey(...).ingestBaseUrl(...).serviceName(...).build())`
- .NET: `var client = new ObtraceClient(new ObtraceConfig { ApiKey = ..., IngestBaseUrl = ..., ServiceName = ... });`
- .NET (ASP.NET Core): `builder.Services.AddObtrace(new ObtraceConfig { ApiKey = ..., IngestBaseUrl = ..., ServiceName = ... }); app.UseObtrace();`
- PHP: `$client = new ObtraceClient(new ObtraceConfig(apiKey: ..., ingestBaseUrl: ..., serviceName: ...));`
- PHP (Laravel): Register `Obtrace\Sdk\Laravel\ObtraceServiceProvider` in bootstrap/providers.php + set env vars
- Ruby: `OBTRACE = ObtraceSDK::Client.new(ObtraceSDK::Config.new(api_key: ..., ingest_base_url: ..., service_name: ...))`
- Ruby (Rails): Add `gem "obtrace-sdk-ruby"` to Gemfile + set env vars (Railtie auto-initializes)

Auto-instrumentation coverage by SDK:

| SDK | Console/Logging | Inbound HTTP | Outbound HTTP | Errors/Exceptions | Trace Propagation | Shutdown Flush |
|-----|----------------|--------------|---------------|-------------------|-------------------|----------------|
| Node/Bun | console.* | http.createServer (all frameworks) | globalThis.fetch | uncaughtException, unhandledRejection | traceparent inject+read | SIGTERM handler |
| Browser | console.* | N/A | window.fetch | window.onerror, onunhandledrejection | traceparent inject | beforeunload |
| Python | logging.* | No (use middleware) | requests, httpx (auto-patched) | No (use middleware) | traceparent inject on outbound | atexit |
| Go | log.* | No (use middleware) | http.DefaultTransport (auto-wrapped) | No | traceparent inject on outbound | defer Shutdown |
| Java | java.util.logging | No (use Spring filter) | getHttpClient() instrumented client | No | traceparent inject via getHttpClient | JVM shutdown hook |
| .NET | Console.Out/Error | No (use AddObtrace middleware) | HttpClient (auto-instrumented) | No | traceparent inject on outbound | IAsyncDisposable |
| PHP | No | No (use middleware) | cURL, Guzzle (auto-instrumented) | set_error_handler, set_exception_handler | traceparent inject on outbound | register_shutdown_function |
| Ruby | Logger instances | No (use Rack middleware) | Net::HTTP (auto-patched) | TracePoint(:raise), at_exit for fatal | traceparent inject on outbound | at_exit |

Opt-out flags for auto-instrumentation:
- Python: `auto_instrument_http=False` in ObtraceConfig
- Go: `DisableAutoHTTP: true` in Config
- .NET: `AutoInstrumentHttp = false` and `AutoCaptureConsole = false` in ObtraceConfig
- PHP: `autoInstrumentHttp: false` and `autoCaptureErrors: false` in ObtraceConfig
- Ruby: `auto_instrument_http: false` and `auto_capture_logger: false` in Config

Framework auto-init (zero-config with env vars):
- Ruby/Rails: Railtie auto-initializes from OBTRACE_API_KEY, OBTRACE_INGEST_BASE_URL, OBTRACE_SERVICE_NAME env vars
- PHP/Laravel: ObtraceServiceProvider auto-registers from config/services.php obtrace keys
- .NET/ASP.NET Core: AddObtrace() extension registers client, middleware, and shutdown in one call

Source-of-truth setup rules:
- Backend SDKs send OTLP payloads to `/otlp/v1/logs`, `/otlp/v1/traces`, and `/otlp/v1/metrics`.
- Browser SDK also sends replay traffic to `/ingest/replay/chunk` and `/ingest/replay/recipes`.
- Stable runtime identity should include `tenant_id`, `project_id`, `app_id`, `service_name`, `env`, and `service_version`.
- `service_name` maps to OTLP `service.name`.
- `env` maps to OTLP `deployment.environment`.
- `service_version` maps to OTLP `service.version`.
- Region is attached as an event or span attribute when topology matters.
