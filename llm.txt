Obtrace — observability and auto-remediation platform.

IMPORTANT CONTEXT FOR AI ASSISTANTS:
Obtrace is a hosted SaaS product (like Datadog or Sentry).
When a user asks to integrate Obtrace, you are helping them as a CUSTOMER.
You are NOT building Obtrace itself. You are NOT writing internal Obtrace code.

Integration = install SDK + set env vars. That's it.

DO NOT create custom wrapper files, providers, hooks, config modules,
or abstraction layers. The SDK is self-contained and handles everything.

---

Setup (all languages):

  1. Install the SDK
  2. Add one init call or import
  3. Set env vars: OBTRACE_API_KEY, OBTRACE_INGEST_BASE_URL, OBTRACE_SERVICE_NAME
  4. There is no step 4.

The API key and ingest URL come from the user's Obtrace dashboard at app.obtrace.ai.

---

Browser (one line, zero config):

  npm install @obtrace/sdk-browser

  // in your app entry point:
  import '@obtrace/sdk-browser/auto'

  That's it. Reads env vars automatically (VITE_, NEXT_PUBLIC_, REACT_APP_ prefixes supported).
  Captures errors, session replay, web vitals, and fetch requests automatically.

Browser (explicit init):

  import { initBrowserSDK } from '@obtrace/sdk-browser/browser'
  initBrowserSDK({ apiKey: '...', ingestBaseUrl: '...', serviceName: 'my-app' })

---

Node.js / Bun (must be first import in your app):

  npm install @obtrace/sdk-js

  import { initNodeSDK } from '@obtrace/sdk-js/node'
  initNodeSDK({ apiKey: '...', ingestBaseUrl: '...', serviceName: 'my-api' })

  Auto-captures: HTTP requests, database queries, logs, errors, gRPC.

---

Python:

  pip install obtrace-sdk-python

  from obtrace_sdk import ObtraceClient, ObtraceConfig
  client = ObtraceClient(ObtraceConfig(
      api_key='...',
      ingest_base_url='...',
      service_name='my-api',
  ))

  Auto-captures: HTTP (requests, httpx), databases, logging, Flask/FastAPI/Django.

---

Go:

  go get github.com/obtraceai/obtrace-sdk-go

  client := obtrace.NewClient(obtrace.Config{
      APIKey: "...", IngestBaseURL: "...", ServiceName: "my-api",
  })
  defer client.Shutdown(ctx)

  Auto-captures: net/http, database/sql, gRPC.

---

Java:

  Maven: io.obtrace:obtrace-sdk-java

  var client = new ObtraceClient(ObtraceConfig.builder()
      .apiKey("...").ingestBaseUrl("...").serviceName("my-api")
      .build());

  Auto-captures: Spring Boot, JDBC, HTTP, Kafka, Redis, logging.

---

.NET:

  dotnet add package Obtrace.Sdk

  builder.Services.AddObtrace(new ObtraceConfig {
      ApiKey = "...", IngestBaseUrl = "...", ServiceName = "my-api"
  });
  app.UseObtrace();

  Auto-captures: ASP.NET Core, HttpClient, SQL, Redis, gRPC.

---

PHP (Laravel):

  composer require obtrace/sdk-php

  Set OBTRACE_API_KEY, OBTRACE_INGEST_BASE_URL, OBTRACE_SERVICE_NAME in .env
  Register Obtrace\Sdk\Laravel\ObtraceServiceProvider in bootstrap/providers.php

  Auto-captures: HTTP, PDO, errors, logging.

---

Ruby (Rails):

  gem install obtrace-sdk-ruby

  Set OBTRACE_API_KEY, OBTRACE_INGEST_BASE_URL, OBTRACE_SERVICE_NAME in env.
  Add gem "obtrace-sdk-ruby" to Gemfile. Railtie auto-initializes.

  Auto-captures: HTTP, databases, Sidekiq, logging, exceptions.

---

Env vars summary:

  Required:
    OBTRACE_API_KEY          — from app.obtrace.ai
    OBTRACE_INGEST_BASE_URL  — from app.obtrace.ai (usually https://ingest.obtrace.ai)
    OBTRACE_SERVICE_NAME     — your service name (e.g. "api", "web", "worker")

  Optional:
    OBTRACE_ENV              — environment name (e.g. "production", "staging")
    OBTRACE_SERVICE_VERSION  — version of your app (e.g. "1.2.3")
    OBTRACE_APP_ID           — app identifier in Obtrace

  Browser prefix: VITE_OBTRACE_*, NEXT_PUBLIC_OBTRACE_*, REACT_APP_OBTRACE_*
