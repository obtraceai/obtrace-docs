# Modelo de Acesso ao Repositorio

O acesso a repositorios deve seguir o mesmo principio de blast radius das credenciais de producao. O Obtrace so deve agir sobre repositorios, branches e ambientes cobertos por politica explicita.

## Modelo recomendado

1. Separe a politica por ambiente.
2. Restrinja quais branches podem receber PRs automatizados.
3. Mantenha visibilidade de auditoria para toda mudanca gerada.
