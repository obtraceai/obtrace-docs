# Fluxo de Aprovacao de PR

Pull requests de remediation devem seguir um caminho de aprovacao previsivel. O Obtrace pode gerar a correcao, mas a politica de merge continua sendo decisao da organizacao.

## Gates recomendados

- Mudancas de alta confianca e baixo risco podem ser abertas automaticamente
- Mudancas de confianca media devem exigir aprovacao
- Mudancas destrutivas ou de alto risco devem permanecer manuais
