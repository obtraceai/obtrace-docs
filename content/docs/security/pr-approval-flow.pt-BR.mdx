# Fluxo de Aprovação de PR

Pull requests de remediation devem seguir um caminho de aprovação previsivel. O Obtrace pode gerar a correção, mas a política de merge continua sendo decisão da organização.

## Gates recomendados

- Mudanças de alta confiança e baixo risco podem ser abertas automaticamente
- Mudanças de confiança media devem exigir aprovação
- Mudanças destrutivas ou de alto risco devem permanecer manuais
