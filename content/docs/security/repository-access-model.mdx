# Repository Access Model

Repository access should follow the same blast-radius principles as production credentials. Obtrace should only touch repositories, branches, and environments covered by explicit policy.

## Recommended model

1. Separate policy by environment.
2. Restrict which branches can receive automated PRs.
3. Keep audit visibility for every generated change.
