# Sem servidor

Runtimes serverless exigem contexto explícito de release e invocação porque os workloads são efemeros e difíceis de reconstruir após um incidente.

## Metadata obrigatória

- Nome da função ou serviço
- Regiao
- Identificador de release
- Correlation id da invocação ou request
