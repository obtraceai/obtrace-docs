# Serverless

Runtimes serverless exigem contexto explicito de release e invocacao porque os workloads sao efemeros e dificeis de reconstruir apos um incidente.

## Metadata obrigatoria

- Nome da funcao ou servico
- Regiao
- Identificador de release
- Correlation id da invocacao ou request
