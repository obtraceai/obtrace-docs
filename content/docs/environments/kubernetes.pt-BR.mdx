# Kubernetes

Use a trilha de Kubernetes quando os incidentes criticos envolvem pods, deployments, jobs, config maps ou secrets.

## O que capturar

- Identidade de namespace, cluster, deployment, pod e container
- Metadata de rollout e imagem
- Sinais de readiness, liveness e restart

## Problemas comuns

- CrashLoopBackOff
- ImagePullBackOff
- OOMKilled
- Readiness probes quebradas
