# Kubernetes

Use the Kubernetes environment path when your critical incidents involve pods, deployments, jobs, config maps, or secrets.

## What to capture

- Namespace, cluster, deployment, pod, and container identity
- Rollout and image metadata
- Readiness, liveness, and restart signals

## Common production issues

- CrashLoopBackOff
- ImagePullBackOff
- OOMKilled
- Broken readiness probes
