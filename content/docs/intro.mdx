Obtrace is an SDK-first observability platform.

You instrument client and server with a consistent model, send telemetry, and validate in the backend.

## Scope of this documentation

1. Initial setup and authentication.
2. Browser and Node/Bun SDK setup.
3. Platform integrations by deployment runtime.
4. Contract references and MCP context.
