A Obtrace é uma plataforma de observabilidade com IA para reduzir MTTR e eliminar troca de contexto durante incidentes. Esta documentação não é só referência de API: é um playbook operacional para sair de zero instrumentação até operação em produção.

2. [Quick Start](/pt-BR/docs/guides/quick-start)
3. [Por que Obtrace](/pt-BR/docs/guides/why-obtrace)
4. [Autenticação](/pt-BR/docs/guides/auth)
5. [Como usar](/pt-BR/docs/guides/how-to-use)

## O Que Você Ganha Com a Obtrace

- Causa raiz assistida por IA correlacionando logs, traces, erros e contexto de sessão.
- Modelo unificado de observabilidade entre frontend e backend.
- Triagem mais rápida com evidência correlacionada, não dashboards desconectados.
- Fluxos opcionais de IA (Ask AI, MCP, `llm.txt`) para agentes e assistentes.

## Caminho de Implementação em 30 Minutos

1. Criar chaves de API e configurar variáveis de ambiente.
2. Instrumentar um serviço backend com o SDK da sua stack.
3. Instrumentar um app frontend/browser (se aplicável).
4. Validar ingestão e sinais básicos.
5. Configurar uma integração de runtime (Kubernetes, Vercel, Docker etc).
6. Adicionar visibilidade de CI/CD com [GitHub Actions](/pt-BR/docs/integrations/github-actions).
