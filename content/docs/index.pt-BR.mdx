# Documentacao Obtrace

Use esta documentacao de acordo com o que voce precisa fazer agora. Ela foi organizada para guiar fluxos completos, nao para obrigar voce a montar passos a partir de referencia espalhada.

## Entradas AI-first

Se voce quer usar a Documentacao Obtrace como contexto para assistentes e clientes MCP, comece por aqui:

- Use o botao flutuante **Ask AI** para respostas contextuais dentro da UI da docs.
- Baixe [llm.txt](/llm.txt?download=1) como indice de autoridade legivel por maquina.
- Baixe [mcp.json](/mcp.json?download=1) para descoberta de recursos via MCP.
- Abra [Downloads de SDK e Contexto para IA](/pt-BR/docs/downloads) para a lista canonica de arquivos.
