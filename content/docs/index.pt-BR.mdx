# Documentação Obtrace

> **Integrando com IA?** Use [`/llms.txt`](/llms.txt) para contexto legível por máquina no padrão [llmstxt.org](https://llmstxt.org), ou conecte via [MCP](/pt-BR/docs/mcp) para acesso a ferramentas em tempo real.

Use esta documentação de acordo com o que você precisa fazer agora. Ela foi organizada para guiar fluxos completos, não para obrigar você a montar passos a partir de referência espalhada.

## Entradas AI-first

Se você quer usar a Documentação Obtrace como contexto para assistentes e clientes MCP, comece por aqui:

- **[`/llms.txt`](/llms.txt)** — índice de autoridade legível por máquina no padrão [llms.txt](https://llmstxt.org). Alimente qualquer LLM para respostas fundamentadas sobre Obtrace.
- **[MCP Server](/pt-BR/docs/mcp)** — conecte Claude, Cursor ou agentes customizados para consultar seus dados Obtrace em tempo real.
- Use o botão flutuante **Ask AI** para respostas contextuais dentro da UI da docs.
- Baixe [mcp.json](/mcp.json?download=1) para descoberta de recursos via MCP.
- Abra [Downloads de SDK e Contexto para IA](/pt-BR/docs/downloads) para a lista canônica de arquivos.
