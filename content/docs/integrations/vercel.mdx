---

## Install

```bash
npm install @obtrace/sdk-js
```

## Configuration

Set environment variables in Vercel project settings:

- Server: `OBTRACE_API_KEY`, `OBTRACE_INGEST_BASE_URL`, `OBTRACE_TENANT_ID`, `OBTRACE_PROJECT_ID`, `OBTRACE_ENV`
- Client: `NEXT_PUBLIC_OBTRACE_API_KEY`, `NEXT_PUBLIC_OBTRACE_INGEST_BASE_URL`, `NEXT_PUBLIC_OBTRACE_TENANT_ID`, `NEXT_PUBLIC_OBTRACE_PROJECT_ID`

References:
- https://vercel.com/docs/environment-variables
- https://nextjs.org/docs/app/guides/environment-variables

## Quickstart

Server (Node runtime):

```ts
import { initNodeSDK } from "@obtrace/sdk-js/node";

export const obtrace = initNodeSDK({
  apiKey: process.env.OBTRACE_API_KEY!,
  ingestBaseUrl: process.env.OBTRACE_INGEST_BASE_URL!,
  serviceName: "vercel-api",
  appId: "vercel-api"
});
```

Client:

```ts
import { initBrowserSDK } from "@obtrace/sdk-js/browser";
```

## Production Hardening

1. Never expose server API keys to browser bundles.
2. Use isolated keys for preview/production.
3. Restrict ingest origin allowlist.

## Troubleshooting

- Missing client telemetry: check `NEXT_PUBLIC_*` vars at build/runtime.
- Missing server telemetry: confirm server env vars and runtime path.
