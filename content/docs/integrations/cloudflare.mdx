## Install

```bash
npm install @obtrace/sdk-js
```

## Configuration

Required bindings:

- `OBTRACE_API_KEY` (secret)
- `OBTRACE_TENANT_ID`
- `OBTRACE_PROJECT_ID`
- `OBTRACE_ENV`

## Quick start

Use `ObtraceClient` in Workers:

```ts
import { ObtraceClient } from "@obtrace/sdk-js";
```

## Production hardening

1. Keep API keys only as secrets.
2. Separate secrets by environment.
3. Validate ingest connectivity from edge runtime.

## Troubleshooting

- Runtime incompatibility: avoid Node entrypoint in Workers.
- Missing bindings: verify Wrangler config and secret names.
