## Visão geral

O Obtrace monitora projetos Supabase via um **agente gerenciado** que se conecta por OAuth. Nenhuma instalação de SDK necessária.

## Configuração

1. Acesse **Conta > Supabase** no painel do Obtrace
2. Clique em **Connect Supabase** para autenticar via OAuth
3. Clique em **Discover Projects** para ver os projetos disponíveis
4. Ative o monitoramento e escolha os coletores (Database, Edge Functions, Auth, Storage, Realtime)

Veja o [guia completo da plataforma](/docs/platforms/supabase) para detalhes.

## O que é coletado

| Coletor | Métricas |
|---------|----------|
| Database | Conexões, latência de queries, queries lentas, locks, tamanhos de tabelas |
| Edge Functions | Invocações, erros, latência por função |
| Auth | MAU, sign-ins, sign-ups |
| Storage | Tamanho, contagem de objetos |
| Realtime | Conexões, mensagens |

## Auto-instrumentação

Ative o toggle **Auto-instrument** para injetar credenciais do Obtrace como secrets do projeto Supabase. Edge Functions que usam o SDK do Obtrace capturam as credenciais automaticamente.

## Desconectando

Remova a conexão em **Conta > Supabase**. Todo monitoramento para imediatamente.
