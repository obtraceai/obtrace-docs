# Como o Obtrace Detecta Incidentes

O Obtrace detecta incidentes combinando sinais de anomalia com contexto de serviço, metadata de release e evidências de erro. O objetivo não é emitir alertas isolados, mas criar um único incidente por problema operacional.

## Entradas

- Explosao de erros
- Mudanças de latência em traces
- Alterações de throughput e saturação
- Deploys e mudanças de configuração
- Metadata do ambiente de runtime

## Fluxo de detecção

```mermaid
flowchart LR
  A[Sinais de runtime] --> B[Correlacao de sinais]
  B --> C[Agrupamento do incidente]
  C --> D[Score de impacto]

```

## Saida esperada

- Um incidente com blast radius estimado
- Traces, logs e evidências de release correlacionados
- Identificador estável para remediation
