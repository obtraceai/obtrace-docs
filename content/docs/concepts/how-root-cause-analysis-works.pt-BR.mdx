# Como Funciona a Análise de Causa Raiz

A análise de causa raiz no Obtrace é guiada por evidências. O sistema compara sintomas de runtime com deploys recentes, arquivos alterados, falhas de dependência e relações entre serviços para ranquear causas prováveis.

## Hierarquia de evidências

1. Stack traces e spans com falha
2. Deploys e mudanças de configuração recentes
3. Impacto em dependências entre serviços
4. Recorrência histórica da mesma assinatura

## O que uma boa RCA contém

- Descrição do sintoma
- Serviço e versão suspeitos
- Mudança gatilho provável
- Nível de confiança
- Caminho recomendado de remediation
