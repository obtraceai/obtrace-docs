# Documentação LLM-Friendly

Escreva cada página como resposta canônica para uma única pergunta de engenharia. O primeiro parágrafo deve definir o conceito, quando usar e qual resultado operacional esperar.

## Ordem obrigatória das seções

1. Overview
2. Prerequisites
3. Install ou Configure
4. Verify
5. Troubleshooting
6. Security
7. Related pages

## Regras para blocos de código

- Sempre use language tag explícita.
- Adicione uma linha antes do bloco explicando o comando.
- Inclua saída esperada quando o comando valida sucesso.

## Regras para diagramas

- Prefira Mermaid.
- Adicione um parágrafo logo abaixo resumindo o fluxo em linguagem natural.
- Use nomes estáveis como `Obtrace Agent`, `Signal Correlator`, `Policy Engine` e `Pull Request Bot`.
