# Instrumentar Python em Producao

Use este fluxo quando o primeiro alvo serio de rollout for um servico Python.

## Sequencia

1. Instale o [SDK Python](/pt-BR/docs/sdks/python)
2. Configure [Autenticacao](/pt-BR/docs/auth)
3. Adicione `service`, `env` e `version`
4. Valide um caminho real de request
5. Conecte [metadata de release](/pt-BR/docs/workflows/connect-release-metadata-to-incidents)
