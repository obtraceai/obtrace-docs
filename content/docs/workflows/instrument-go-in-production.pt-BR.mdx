# Instrumentar Go em Producao

Use este fluxo quando o primeiro alvo de rollout for uma API ou worker em Go.

## Sequencia

1. Instale o [SDK Go](/pt-BR/docs/sdks/go)
2. Configure [Autenticacao](/pt-BR/docs/auth)
3. Adicione identidade estavel de servico
4. Valide um caminho sensivel a latencia
5. Conecte [metadata de release](/pt-BR/docs/workflows/connect-release-metadata-to-incidents)
