## Scope

This blueprint defines minimum instrumentation for Dotnet api services.

## Required outputs

1. Request/response logs with correlation IDs.
2. Service metrics for latency and error rate.
3. Spans across DB and outbound HTTP.

## Deployment checklist

1. Configure env vars and secrets.
2. Initialize SDK at process bootstrap.
3. Validate one end-to-end transaction.
4. Add alerts for ingestion errors.
