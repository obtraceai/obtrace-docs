## JavaScript

- Repo: `obtraceai/obtrace-sdk-js`
- Git clone:

```bash
git clone git@github.com:obtraceai/obtrace-sdk-js.git
```

- Package:

```bash
npm install @obtrace/sdk-js
# or
bun add @obtrace/sdk-js
```
