# Ingestion API

A ingestion API recebe telemetria com identidade estavel e metadata de autorizacao.

## Campos obrigatorios

- API key
- identidade de tenant ou projeto
- service
- env
- version

## Resultado esperado

Os eventos sao aceitos, carimbados com tempo e correlacionados com o contexto de runtime existente.
