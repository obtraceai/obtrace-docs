# API de Ingestão

A ingestion API recebe telemetria com identidade estável e metadata de autorização.

## Campos obrigatórios

- API key
- identidade de tenant ou projeto
- service
- env
- version

## Resultado esperado

Os eventos são aceitos, carimbados com tempo e correlacionados com o contexto de runtime existente.
