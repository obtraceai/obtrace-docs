# Remediation API

A remediation API representa o caminho controlado entre a evidência do incidente e uma mudança proposta de código.

## Areas tipicas do contrato

- Identificador do incidente
- Payload de evidência de causa raiz
- Resultado da avaliação de política
- Repositório alvo e estratégia de branch
