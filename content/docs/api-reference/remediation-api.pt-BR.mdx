# Remediation API

A remediation API representa o caminho controlado entre a evidencia do incidente e uma mudanca proposta de codigo.

## Areas tipicas do contrato

- Identificador do incidente
- Payload de evidencia de causa raiz
- Resultado da avaliacao de politica
- Repositorio alvo e estrategia de branch
