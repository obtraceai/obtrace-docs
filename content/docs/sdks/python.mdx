## Install

```bash
pip install obtrace-sdk-python
```

## Configuration

```python
import os

from obtrace_sdk import ObtraceClient, ObtraceConfig

client = ObtraceClient(
    ObtraceConfig(
        api_key=os.getenv("OBTRACE_API_KEY"),
        ingest_base_url=os.getenv("OBTRACE_INGEST_BASE_URL"),
        tenant_id=os.getenv("OBTRACE_TENANT_ID"),
        project_id=os.getenv("OBTRACE_PROJECT_ID"),
        app_id="checkout-api",
        service_name="checkout-api",
        service_version=os.getenv("OBTRACE_SERVICE_VERSION", "2026.03.10"),
        env=os.getenv("OBTRACE_ENV", "prod"),
        validate_semantic_metrics=True,
        debug=os.getenv("OBTRACE_DEBUG") == "1",
    )
)
```

Obtrace Python sends OTLP payloads to the core ingest endpoints:

- `POST /otlp/v1/logs`
- `POST /otlp/v1/traces`
- `POST /otlp/v1/metrics`

## Canonical runtime identity

Set stable identity in `ObtraceConfig`:

- `service_name`
- `env`
- `service_version`
- `tenant_id`
- `project_id`
- `app_id`

Add region only where it matters operationally:

```python
runtime_attrs = {
    "cloud.region": os.getenv("AWS_REGION", "us-east-1"),
    "deployment.ring": "stable",
}
```

This matches the ingest/core contract:

- `service_name` -> OTLP `service.name`
- `env` -> OTLP `deployment.environment`
- `service_version` -> OTLP `service.version`
- `tenant_id`, `project_id`, `app_id` -> scoped ingest identity

## Quick start

```python
from obtrace_sdk import SemanticMetrics

client.log("info", "service.started")
client.metric(SemanticMetrics.RUNTIME_CPU_UTILIZATION, 0.42)
client.span(
    "checkout.authorize",
    attrs={
        "feature.name": "checkout",
        "db.system": "postgresql",
        "cloud.region": runtime_attrs["cloud.region"],
    },
)
client.flush()
```

## FastAPI example

```python
import os

from fastapi import FastAPI
from obtrace_sdk import ObtraceClient, ObtraceConfig, SemanticMetrics
from obtrace_sdk.http import fastapi_middleware

client = ObtraceClient(
    ObtraceConfig(
        api_key=os.getenv("OBTRACE_API_KEY"),
        ingest_base_url=os.getenv("OBTRACE_INGEST_BASE_URL"),
        tenant_id=os.getenv("OBTRACE_TENANT_ID"),
        project_id=os.getenv("OBTRACE_PROJECT_ID"),
        app_id="checkout-api",
        service_name="checkout-api",
        service_version=os.getenv("OBTRACE_SERVICE_VERSION", "2026.03.10"),
        env=os.getenv("OBTRACE_ENV", "prod"),
    )
)

app = FastAPI()
app.middleware("http")(fastapi_middleware(client))

@app.get("/healthz")
async def healthz():
    client.log("info", "healthz.request")
    client.metric(SemanticMetrics.RUNTIME_CPU_UTILIZATION, 0.41)
    client.span("http.server GET /healthz", attrs={
        "http.method": "GET",
        "http.route": "/healthz",
        "cloud.region": os.getenv("AWS_REGION", "us-east-1"),
    })
    return {"ok": True}
```

## Validation checklist

- the same `service`, `env`, and `version` survive restarts and deploys
- one real request path emits at least one log and one trace
- `401/403` does not appear during telemetry submission
- `cloud.region` is present when the service is multi-region

See also: [Semantic Metrics](/docs/sdks/semantic-metrics)

## Production hardening

1. Keep keys in secret manager.
2. Configure bounded queue and retry.
3. Validate volume and error rate after deploy.

## Troubleshooting

- `401/403`: invalid key or wrong tenant/project.
- No data: startup path not initializing SDK.
- Event drops: queue saturation or worker crash.
