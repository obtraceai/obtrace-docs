## Install

```bash
./mvnw dependency:get -Dartifact=io.obtrace:obtrace-sdk-java:1.0.0
```

## Configuration

```java
import io.obtrace.sdk.core.ObtraceClient;
import io.obtrace.sdk.model.ObtraceConfig;

ObtraceConfig cfg = new ObtraceConfig();
cfg.apiKey = System.getenv("OBTRACE_API_KEY");
cfg.ingestBaseUrl = System.getenv("OBTRACE_INGEST_BASE_URL");
cfg.tenantId = System.getenv("OBTRACE_TENANT_ID");
cfg.projectId = System.getenv("OBTRACE_PROJECT_ID");
cfg.appId = "checkout-api";
cfg.serviceName = "checkout-api";
cfg.serviceVersion = System.getenv().getOrDefault("OBTRACE_SERVICE_VERSION", "2026.03.10");
cfg.env = System.getenv().getOrDefault("OBTRACE_ENV", "prod");
cfg.validateSemanticMetrics = true;
cfg.debug = "1".equals(System.getenv("OBTRACE_DEBUG"));

ObtraceClient client = new ObtraceClient(cfg);
```

The Java SDK sends to:

- `POST /otlp/v1/logs`
- `POST /otlp/v1/traces`
- `POST /otlp/v1/metrics`

## Canonical runtime identity

Set `serviceName`, `env`, and `serviceVersion` once in `ObtraceConfig`. Add region on spans or logs where topology matters.

```java
Map<String, Object> runtimeAttrs = Map.of(
    "cloud.region", System.getenv().getOrDefault("AWS_REGION", "us-east-1"),
    "deployment.ring", "stable"
);
```

This aligns with the ingest/core contract:

- `serviceName` -> OTLP `service.name`
- `env` -> OTLP `deployment.environment`
- `serviceVersion` -> OTLP `service.version`
- `tenantId`, `projectId`, `appId` -> scoped ingest identity

## Quick start

```java
import io.obtrace.sdk.core.SemanticMetrics;
import java.util.Map;

client.log("info", "service.started", null);
client.metric(SemanticMetrics.RUNTIME_CPU_UTILIZATION, 0.41, "1", null);
client.span("checkout.charge", null, null, null, "", Map.of(
    "feature.name", "checkout",
    "payment.provider", "stripe",
    "cloud.region", runtimeAttrs.get("cloud.region")
));
client.flush();
```

## Spring Boot startup example

```java
@Configuration
public class ObtraceBootstrap {
  @Bean
  public ObtraceClient obtraceClient() {
    ObtraceConfig cfg = new ObtraceConfig();
    cfg.apiKey = System.getenv("OBTRACE_API_KEY");
    cfg.ingestBaseUrl = System.getenv("OBTRACE_INGEST_BASE_URL");
    cfg.tenantId = System.getenv("OBTRACE_TENANT_ID");
    cfg.projectId = System.getenv("OBTRACE_PROJECT_ID");
    cfg.appId = "checkout-api";
    cfg.serviceName = "checkout-api";
    cfg.serviceVersion = System.getenv().getOrDefault("OBTRACE_SERVICE_VERSION", "2026.03.10");
    cfg.env = System.getenv().getOrDefault("OBTRACE_ENV", "prod");
    return new ObtraceClient(cfg);
  }
}
```

## Validation checklist

- request paths and failure paths emit traces with the same `service`, `env`, and `version`
- executor, timeout, and OOM incidents can be tied to one release value
- no `401/403` occurs during OTLP submission
- region is present when the JVM service is multi-region
