## Status

Este SDK está em validação e ainda não é GA.

## Instalação planejada

```bash
cargo add obtrace-sdk
```

## Foco planejado

1. Transporte assíncrono de alta vazão.
2. Interoperabilidade com OpenTelemetry.
3. Modo de baixa alocação para serviços com budget de latência rígido.
